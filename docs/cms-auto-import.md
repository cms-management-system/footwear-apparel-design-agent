# CMS 证据包自动导入

## 问题与价值
手填编号妨碍设计师和评委完成 CMS 协作。自动发现当前空间已批准的需求，按内容选择即可创建设计，减少复制和编号出错。

## 适配与契约
沿用 Next.js 15 / React 19、CSS 模块和 FastAPI，不新增依赖。
- CMS GET /api/packages?status=approved&limit=21&offset=0：design 密钥，仅 approved，按 created_at 和 package_id 降序；新增非负 offset。
- Design GET /api/cms/packages?offset=0：服务端转发，返回 {items: CmsPackage[], next_offset: number|null}，每页20，读取21条判断后页。错误沿用 {error:{code,message}}，密钥仅在后端。
- 创建项目时再次校验审批并持久化完整快照。
- 页面进入、恢复可见、窗口聚焦及可见时每60秒自动更新。包含加载、空列表、错误重试和加载更多状态。更新不触发收费；点选开始后走既有对话流程。

## 验收
1. 不输入编号、不点击读取，即展示需求摘要；点开始带入正确编号和需求。
2. 未批准数据不可读；其他访客隔离；空空间提示先去 CMS 批准。
3. 网络错误可重试；返回页面获取最新数据；并发刷新不覆盖、卸载不回写。
4. 分页无重复编号，busy 防重复开始；旧记录保留。
5. 类型、Lint、测试和构建通过；公网真实列表与选用、刷新关联验证；桌面和390px布局检查。

## 发布和回退
沿用同一域名及已有资源，无数据迁移。备份代码和产物；确认无生成任务后重启后端，可恢复备份回退。

## 验收结果
已上线。前端47项、设计CMS7项、CMS读取11项通过；Lint无警告，类型与生产构建通过。真实自动列表、点击选用、要求生成、刷新持久化、隔离及旧图完整性通过。390px无横向溢出。本轮没有新图片调用，已有图片生成能力沿用前轮验收。
